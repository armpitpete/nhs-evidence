# NHS Accountability Report — weekly prototype template

Status: **prototype; reporting format not frozen**

## Purpose

Answer: **What materially changed this week that should update our understanding of NHS delivery, accountability or system performance?**

The report is not a news digest.

## Sections

1. **Major changes** — material transitions in policy, implementation, scope, deadlines, ownership, metrics or outcomes.
2. **New commitments** — testable promises, targets, obligations or publication commitments first captured this week.
3. **Promise status changes** — earlier state → later evidence → current evidence-backed status.
4. **Commitments fulfilled / improvements demonstrated** — positive delivery evidence.
5. **Commitments under pressure** — delayed, changed, partially fulfilled, unverifiable or approaching deadlines; do not equate uncertainty with failure.
6. **Demonstrated failures** — expectation, observed divergence, affected population/service and evidence strength.
7. **Evidence gaps** — where a fair judgment cannot yet be made.
8. **Remedy evidence** — official recommendations, evaluated interventions, comparators or proposals, with confidence kept separate from failure severity.
9. **Yorkshire/local implications** — only where local evidence supports comparison.
10. **Next accountability checks** — the small set of observable events that matter next.

## Per-item minimum

For each material change:

- Earlier state
- Later state/evidence
- Concrete transition
- Current status
- Why it matters
- Explanation status
- What remains unknown
- Next check

Do not pad empty sections.

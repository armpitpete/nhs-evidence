# NHS Accountability Report — 2026-W39 prototype

**Internal prototype — partial evidence window through 22 September 2026.**

This is deliberately **not** a complete Monday–Sunday Week 39 report. Its purpose is to test the accountability model against evidence already available; the scheduled T-114 run remains responsible for the full weekly window.

## What materially changed

### Martha's Rule: contractual commitment now has observable implementation evidence

**Earlier position:** NHS trusts and foundation trusts must implement the three core components by 31 March 2027.

**Later evidence:** phase 3 has begun; setting-level collection has started; aggregate programme activity is substantial.

**Current status:** **implementation-started**.

**What we cannot say:** the national commitment is not yet proven fulfilled, and the deadline has not been missed. ED availability is not universal on the evidence captured.

**Next check:** WATCH-NHS-2026-0002.

### ONS: two imminent publication commitments now have fixed test points

The release calendar provides observable dates for weekly provisional deaths (23 September) and Death Certification Reform 2025 (25 September).

**Current status:** **announced / due shortly**.

Publication must be observed before the commitment can be marked fulfilled.

### Thirlwall-related actions: obligation captured, delivery test still incomplete

NHS England's bulletin establishes that trusts/ICBs were asked to review recommendations/immediate actions and follow up.

The underlying letter has not yet been captured, so the system does not yet have a complete deadline/success criterion.

**Current status:** **announced; delivery not yet assessable**.

This is an evidence gap, not a failure finding.

## Commitments fulfilled this window

**None yet proven in the live pilot corpus.**

The report intentionally leaves this section empty rather than manufacturing a positive or negative result.

## Demonstrated failure requiring attention

### Mental-health crisis care in emergency departments

HSSIB's national investigation identifies prolonged waits, unsuitable environments, workforce pressures and wider pathway gaps.

This is **demonstrated national patient-safety problem evidence**, but it is **not currently a broken-promise finding** in this repository because no relevant accepted DHSC/NHS England delivery commitment has yet been captured.

## Remedy evidence

HSSIB recommendations R/2026/097 and R/2026/098 provide **official-recommendation-level** remedy evidence covering operational/design standards, accountability, shared-care/escalation, workforce planning and measurement.

Evidence record: REC-NHS-2026-0012.

The recommendations are not described as proven solutions and are not treated as government/NHS commitments until an authoritative response creates one.

## Improvement / positive delivery evidence

Martha's Rule programme activity establishes real implementation progress. York and Scarborough public information establishes 24/7 Martha's Rule access for adult and paediatric inpatients.

This does not prove York/Scarborough ED availability or outcome effectiveness.

## Yorkshire/local accountability

Two bounded local questions remain:

- when does Martha's Rule become demonstrably available in York/Scarborough emergency departments?
- does operational evidence for York/Scarborough mental-health crisis care reproduce, avoid or differ from HSSIB's national findings?

No local failure is inferred from absence of public operational data.

## Direction-of-travel finding

**None yet.**

Two days of live evidence are insufficient to claim a sustained NHS direction change.

- 25 September: observe Death Certification Reform publication.

## Prototype finding

The v0.1 model successfully distinguishes:

- a real commitment with implementation in progress;
- a commitment not yet due;
- an obligation whose delivery criteria remain incomplete;
- a demonstrated service problem with remedy recommendations but no captured accepted implementation promise.

It does so without rewriting the original positions or converting uncertainty into failure.

# Daily NHS Scans

One dated receipt is written for every completed T-113 daily scan.

Suggested path:

`scans/YYYY/MM/YYYY-MM-DD.md`

Each receipt should record:

- scan window
- authoritative sources checked
- discovery/news sources checked
- due watches checked
- expected events checked
- new source IDs
- new evidence-record IDs
- updated record IDs
- new or updated lead IDs
- new or updated watch IDs
- negative findings that materially tested a lead
- major observations
- known gaps or inaccessible sources
- whether the day produced no material change

A scan receipt is an audit trail of what was actually checked. It is not itself evidence for a substantive NHS claim.

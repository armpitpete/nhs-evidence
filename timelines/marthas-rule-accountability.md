# Martha's Rule — accountability timeline

## Preserved baseline

**2 March 2026 / 2026–27 contract:** NHS England's core standards and the NHS Standard Contract establish the obligation for NHS trusts and foundation trusts to implement all three core components by **31 March 2027**.

Evidence: REC-NHS-2026-0006, SRC-NHSE-MR-CORE-STANDARDS-2026-03-02, SRC-NHSE-STANDARD-CONTRACT-MR-2026-27.

## Later evidence

- **April 2026:** NHS England says phase 3 commenced, extending introduction into emergency departments, maternity and neonatal settings.
- **June 2026:** setting-level data collection began.
- **July 2026:** NHS England reports 19,177 escalation calls since September 2024; aggregate activity demonstrates the programme is operating, but not universal local implementation.
- **22 September 2026:** NHS England's overview says maternity, neonatal and ED settings are generally not yet universally available. York/Scarborough public information establishes 24/7 adult/paediatric inpatient access, not ED coverage.

Status evidence: REC-NHS-2026-0011.

## Current accountability state

**implementation-started**

The 31 March 2027 deadline has not passed. Neither fulfilled nor unmet is supported.
